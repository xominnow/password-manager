# Lockbox v0.1.0 — final capstone source snapshot

Python/Kivy, single-user, local-only Android password-manager **prototype**.
This debug pre-release is for evaluation with synthetic credentials, not a
production-audited password manager or Play Store release.

Download the APK under Assets; the source ZIP/TAR is for developers, not an
installer. Requires Android 8.0/API 26 or newer and ARM64/ARMv7 hardware.
Both this build and the preserved historical `Lockbox_V0.1.0` asset show app
version 0.1.0; use this release tag and checksum to distinguish them.

Features: encrypted local vault, master login, 16-character alphanumeric recovery
key and reset, credential CRUD/search, strong-password generation and feedback,
explicit copying with best-effort expiry, two-minute inactivity lock, secure
window protection, revised scrolling and sensitive-screen cleanup.

## Important limitations

Copied passwords can remain in keyboard history; that fix was explicitly
skipped by the user. Clipboard erasure and memory zeroization are not guaranteed.
No backup/export, cloud sync, device transfer, autofill or biometrics.
Uninstalling/clearing data or losing the phone can permanently lose the vault;
the recovery key cannot restore deleted data. Save it privately at setup.
Fresh-setup confirmation, wider devices/accessibility, 100-entry performance,
independent clean builds and security auditing retain verification gaps.

For an existing vault, install as an update retaining package/signing identity;
do not uninstall or clear data. The Git snapshot contains no personal vaults,
credentials or private signing keys. Test fixtures and UI captures are synthetic.
